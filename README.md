# Smart Budget and Expense Tracker

A full-stack web application that helps users manage personal finances efficiently through expense tracking, budget monitoring, expense splitting, financial reports, and smart spending predictions.

---

## Features

### User Authentication
- Secure user registration and login
- Session management
- Logout functionality

### Expense Management
- Add and manage expenses
- Track daily transactions
- Add transaction notes

### Budget Tracking
- Monitor spending habits
- Manage personal budgets

### Expense Splitting
- Split expenses among multiple users
- Simplified shared expense handling

### Reports & Analytics
- Generate financial reports
- View spending summaries and analytics

### Smart Predictions
- Predict future expenses
- Analyze spending patterns
