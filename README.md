# Smart Budget and Expense Tracker

A full-stack web application that helps users manage personal finances efficiently through expense tracking, budget monitoring, expense splitting, financial reports, and smart spending predictions.

---

## Features

### User Authentication
- Secure user registration and login
- Session management
- Logout functionality

### Expense Management
- Add and manage expenses
- Track daily transactions
- Add transaction notes

### Budget Tracking
- Monitor spending habits
- Manage personal budgets

### Expense Splitting
- Split expenses among multiple users
- Simplified shared expense handling

### Reports & Analytics
- Generate financial reports
- View spending summaries and analytics

### Smart Predictions
- Predict future expenses
- Analyze spending patterns

## Installation & Setup

### Clone Repository

```bash
git clone https://github.com/SrujanaSreeVanipenta/Expense-Tracker.git
cd Expense-Tracker
```

---

### Install XAMPP

Download and install XAMPP:

https://www.apachefriends.org/index.html

---

### Start Apache & MySQL

Open XAMPP Control Panel and start:
- Apache
- MySQL

---

### Database Setup

1. Open phpMyAdmin
2. Create a new database
3. Import the SQL file into the database

---

### Run the Project

Move the project folder into:

```plaintext
xampp/htdocs/
```

Open browser:

```plaintext
http://localhost/Expense-Tracker
```
